🗡️ Mage Knight Hilfe

Spielziel

Besiege alle Feinde auf der Karte, um zu gewinnen!

Spielablauf

  1. Karten spielen - Klicke auf Karten in deiner Hand
  2. Bewegen - Klicke auf Hex-Felder um dich zu bewegen
  3. Kämpfen - Betritt Felder mit Feinden
  4. Zug beenden - Klicke "Zug beenden" für neue Karten

Wichtige Tastenbelegung

  • Linksklick auf Karte - Spielt Basis-Wirkung
  • Rechtsklick auf Karte - Spielt Karte seitlich (+1)
  • Klick auf Hex - Bewegt Held oder wählt Feld aus
  • Strg+Z / ↩️ Button - Letzte Aktion rückgängig machen

Held Stats

  • 🛡️ Rüstung - Reduziert erhaltenen Schaden
  • 🎴 Handlimit - Max. Karten auf der Hand
  • 💔 Verletzungen - Blockieren Kartenslots
  • ⭐ Ruhm - Punkte für besiegte Feinde
  • 💬 Ansehen - Beeinflusst Interaktionen

Kartentypen

🌿 Grüne Karten

Bewegungskarten - Geben Bewegungspunkte

⚔️ Rote Karten

Angriffskarten - Fügen Feinden Schaden zu

🛡️ Blaue Karten

Block-Karten - Blocken Feindangriffe

💬 Weiße Karten

Einfluss/Heilung - Für Interaktionen

Kartenwirkungen

  • Basic - Grundwirkung ohne Mana
  • Strong - Verstärkte Wirkung mit Mana (in Entwicklung)
  • Seitlich spielen - Jede Karte kann für +1 Bewegung/Angriff/Block/Einfluss gespielt werden

Kartenverwaltung

Am Ende deines Zugs:

  • Gespielte Karten → Ablage
  • Ziehe neue Karten bis Handlimit
  • Wenn Deck leer: Ablage wird gemischt

Bewegung Schritt für Schritt

  1. Spiele eine oder mehrere grüne Bewegungskarten
  2. Bewegungspunkte werden addiert (oben links im Panel)
  3. Erreichbare Felder werden violett hervorgehoben
  4. Klicke auf ein hervorgehobenes Feld
  5. Dein Held bewegt sich dorthin
  6. Bewegungskosten werden abgezogen

Bewegungskosten

Jedes Terrain hat unterschiedliche Kosten:

  • 🌾 Ebenen - 2 Punkte
  • 🌲 Wald - 3 Punkte
  • ⛰️ Hügel - 3 Punkte
  • 🏔️ Berge - 5 Punkte
  • 🏜️ Wüste - 3 Punkte
  • ☠️ Ödland - 3 Punkte
  • 💧 Wasser - Unpassierbar

Tipps

  • Plane deine Route vorher durch
  • Ebenen sind am günstigsten
  • Vermeide Berge wenn möglich
  • Du kannst mehrere Bewegungskarten kombinieren

Kampf starten

Ein Kampf beginnt automatisch, wenn du ein Feld mit einem Feind betrittst.

Kampfphasen

1️⃣ Block-Phase
  • Spiele blaue Block-Karten
  • Blocke den Feind-Angriff vollständig
  • Block ≥ Feind-Angriff → Feind geblockt
  • Klicke "Zug beenden" für nächste Phase
2️⃣ Schadens-Phase
  • Ungeblockte Feinde fügen Schaden zu
  • Schaden / Deine Rüstung = Verletzungen (aufgerundet)
  • Verletzungen kommen auf deine Hand
  • Phase läuft automatisch ab
3️⃣ Angriffs-Phase
  • Spiele rote Angriffs-Karten
  • Angriff ≥ Feind-Rüstung → Feind besiegt
  • Erhalte Ruhm für besiegte Feinde
  • Kampf endet automatisch

Feind-Stats

  • 🛡️ Rüstung - Muss überwunden werden
  • ⚔️ Angriff - Schaden den der Feind zufügt
  • ⭐ Ruhm - Belohnung für Sieg

Kampf-Tipps

  • Blocke starke Gegner wenn möglich
  • Spare Angriffskarten für schwere Feinde auf
  • Kombiniere mehrere Karten für große Wirkungen
  • Verletzungen können nur durch Rasten/Heilung entfernt werden

  • Plane deine Route entlang von Ebenen wenn möglich
